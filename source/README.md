# source

The source port: the bytes of a named value, and a label that tells when they changed. A **config source** returns a signed configuration document; a **secret source** returns a secret. As a ConnectRPC contract (`atoom.source.v1alpha1.SourceService`: `Capabilities`, `Read`, `Watch`), its stubs in Go and Rust, its documentation, and a conformance kit.

| | Go | Rust |
| --- | --- | --- |
| Port (contract and stubs) | module `github.com/truvity/atoom/source`; stubs in `gen/atoom/source/v1alpha1` (committed) and `gen/atoom/source/v1alpha1/sourcev1alpha1connect` | crate `atoom-source`: `atoom_source::atoom::source::v1alpha1` (generated by `build.rs`) |
| Conformance kit | the binary below runs against any driver | crate [`atoom-source-conformance`](conformance/README.md), binary `source-conformance --socket PATH --present NAME --bytes FILE` |
| Drivers | [`source/file`](file/README.md) in Go (module `github.com/truvity/atoom/source/file`, a directory of signed config documents, linked in process) | [`atoom-source-file`](file/README.md) (the same, as a sidecar), [`atoom-source-credential`](credential/README.md) (systemd credentials) |

The contract is [proto/atoom/source/v1alpha1/source.proto](proto/atoom/source/v1alpha1/source.proto). Its rules in prose are in [docs/source-port.md](docs/source-port.md). Where the code came from is in [provenance](../docs/provenance.md#source).

A Go consumer links a driver in process by mounting its `sourcev1alpha1connect` handler on an in-memory transport ([in process](../socket/docs/in-process.md); `source/file` is the Go driver for it), or dials one that serves on a socket; a Rust consumer registers the driver's `router()` on its own server, or runs the thin main as a sidecar.

Dependencies are the ConnectRPC and Protobuf runtimes and nothing else: the isolation check holds it to that.

Status: v1alpha1. A field may change until the contract becomes v1beta1; a breaking change raises the minor version of the repository.
