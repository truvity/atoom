# index

The index port: a search index of the entries of append-only logs, under the host's declaration of the log kinds that have an index and of the columns beyond the fixed ones ([record 0025](../docs/decisions/0025-generic-blob-transport-and-index.md)). A **write side** keeps, for each log, the cursor of the last checkpoint that was verified and indexed, and takes the rows of a batch together with the next cursor in one step; a **read side** searches. As a ConnectRPC contract (`atoom.index.v1alpha2`: `IndexService` with `GetCursor` and `Apply`, `IndexReadService` with `Search`), its stubs in Go and Rust, its documentation, and a conformance kit.

| | Go | Rust |
| --- | --- | --- |
| Port (contract and stubs) | module `github.com/truvity/atoom/index`; stubs in `gen/atoom/index/v1alpha2` (committed) and `gen/atoom/index/v1alpha2/indexv1alpha2connect` | crate `atoom-index`: `atoom_index::atoom::index::v1alpha2` (generated by `build.rs`) |
| The declaration | `index.ParseDeclaration`, `index.CheckDeclaration` | `atoom_index::declaration::Schema` |
| Conformance kit | the binary below runs against any driver | crate [`atoom-index-conformance`](conformance/README.md), binary `index-conformance --socket PATH --read-socket PATH` (and `--print-declaration`) |
| Drivers | none in Go | [`atoom-index-sqlite`](sqlite/README.md) (one SQLite file with FTS5) |

The contract is [proto/atoom/index/v1alpha2/index.proto](proto/atoom/index/v1alpha2/index.proto). Its rules in prose are in [docs/index-port.md](docs/index-port.md). Where the code came from is in [provenance](../docs/provenance.md#index).

A Go consumer links a driver in process by mounting its `indexv1alpha2connect` handlers on an in-memory transport, or dials one that serves on a socket; a Rust consumer registers the driver's `router()` of each side on its own server, or runs the thin main as a sidecar.

Dependencies are the ConnectRPC and Protobuf runtimes (and, in Rust, `serde_json` of their graph for the declaration's JSON) and nothing else: the isolation check holds it to that.

Status: v1alpha2 (from 0.9.0; `v1alpha1`, with audit's fixed columns, is removed in the same release, record 0025). A field may change until the contract becomes v1beta1; a breaking change raises the minor version of the repository.
