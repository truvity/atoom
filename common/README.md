# common

The types every atoom port and driver speaks: `Refusal` and `IndexEntry`, in the proto package `atoom.common.v1alpha1`, with their Go and Rust stubs and the helpers that build and read a refusal.

| | Go | Rust |
| --- | --- | --- |
| Library | module `github.com/truvity/atoom/common` | crate `atoom-common` |
| Messages | `github.com/truvity/atoom/common/gen/atoom/common/v1alpha1` (committed) | `atoom_common::atoom::common::v1alpha1` (generated by `build.rs`) |
| Refusal helpers | package `github.com/truvity/atoom/common/refusal`: `New`, `Reason`, `FieldPath`, `Strip` | module `atoom_common::refusal`: `new`, `detail`, `reason` |

The contract is [proto/atoom/common/v1alpha1/common.proto](proto/atoom/common/v1alpha1/common.proto). The documentation is in [docs/refusal.md](docs/refusal.md). Where the code came from is in [PROVENANCE.md](PROVENANCE.md).

Dependencies are the ConnectRPC and Protobuf runtimes and nothing else (the Rust crate also names `serde` and `base64`, which are in the ConnectRPC runtime's own graph): the isolation check holds it to that.

Status: v1alpha1. A field may change until the contract becomes v1beta1; a breaking change raises the minor version of the repository.
